# HIS — Hogares, Instalaciones y Soluciones

Sitio web informativo de HIS (HTML, CSS y JS puro, sin dependencias).

- `index.html` — página principal (landing)
- `his-productos-finalizados.html` — catálogo de proyectos
- `his-blog-*.html` — artículos del blog
- `contacto.html` — contacto guiado por Cato
- `img/` — imágenes

Publicado con GitHub Pages. Importante: los nombres de archivo distinguen mayúsculas y minúsculas
(`Cocina2.jpg` y `cocina2.jpg` son archivos distintos).
